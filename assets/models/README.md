# Model Image Slots

Put your custom PNG "models" here to skin the prototype.

## Supported file names

- `player.png`
- `ghost.png`
- `box.png`
- `wall.png`
- `button_on.png`
- `button_off.png`
- `door_open.png`
- `door_closed.png`
- `goal.png`

The game will automatically load any image that exists and fall back to built-in simple shapes when an image is missing.

Tip: Use square images (64x64, 128x128, etc.) for best results.
