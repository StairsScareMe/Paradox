# Model Image Slots

Put your custom PNG files here to skin the prototype.

## Supported file names

- `player.png`
- `ghost.png`
- `box.png`
- `wall.png`
- `button_on.png`
- `button_off.png`
- `door_open.png`
- `door_closed.png`
- `goal.png`

The game loads these files automatically if they exist.

You can also upload images in-game (Custom Photos / Models panel), which overrides these files in your browser until cleared.
